ここまでの演習では、ユーザーエクスペリエンスの改善や機能追加を目的とした 3 つのタスクを Copilot クラウドエージェントに依頼しました。クラウドエージェントは非同期かつ自律的に動作しますが、タスクを監視することも重要です。

GitHub.com の[エージェントページ][agents-page]など、クラウドエージェントに割り当てたタスクを管理するツールがいくつかあります。このミッションコントロールでは、オープンなプルリクエスト (PR) があるすべてのエージェントタスクを確認できます。実行された操作を調べたり、進行中のセッションに追加の指示を出したりできます。

このレッスンでは、次のことを行います。

- エージェントページでクラウドエージェントのタスクを監視します。
- 進行中のセッションに追加機能を依頼し、作業の方向を調整します。

## シナリオ

ハイコントラストモードの作成をエージェントに依頼した後、チームはライトモードも追加することにしました。サイトのスタイルを更新し、切り替え機能を追加する作業がすでに進んでいるため、ライトモードも含めるのが合理的です。ハイコントラストに加えてライトモードも追加されるよう、エージェントの作業を誘導します。

## Copilot クラウドエージェントのタスクを確認する

Copilot クラウドエージェントに割り当てたタスクの現在の状態を確認します。

1. [Copilot エージェントページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左側のペインにあるタスクの一覧を確認します。割り当てた次のタスクが表示されます。
    - コードのドキュメントを更新する。
    - ゲームを変更するアプリケーションプログラミングインターフェイス (API) を生成する。
    - Web サイトにハイコントラストモードを追加する。
3. 実行中のタスクを選択し、Copilot が実行した作業を確認します。次のような操作が含まれる場合があります。
    - リポジトリからコードをチェックアウトする。
    - Copilot が作業する環境を作成する。
    - モデルコンテキストプロトコル (MCP) サーバーを設定する。
    - 割り当てられたタスクを完了するためにさまざまな操作を実行する。

> [!NOTE]
> 表示される手順は、Copilot の作業状況や採用した方法によって異なります。

4. 右側に表示される PR ペインも確認します。PR と変更されたファイルを表示して、作業をさらに監視できます。

## クラウドエージェントの作業を誘導する

実行中のタスクを確認できたので、ハイコントラストモードの作業中にライトモードの切り替えも追加するよう Copilot に依頼します。

1. ハイコントラストモードの追加に関するセッションを選択します。正確なタイトルは、Copilot が付けた名前や作業状況によって異なります。

    ![ミッションコントロールのアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業を開始したことが示されるまで、数分間セッションを確認します。次の例のようなメッセージが表示されます。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

    ```plaintext
    While we are working on a high contrast mode, let's also add a light mode. There should be a switch for this mode as well where users can select their desired display mode.
    ```

    ![エージェントページで、Copilot の作業中にアクティブなセッションを誘導するダイアログが強調表示されたタスクのスクリーンショット](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを受け取り、作業に追加する様子を確認します。

## Copilot に作業を続けてもらう

これまでと同じように、Copilot は更新されたタスクに取り組みます。メッセージを送信した時点で実行中だった手順を完了した後、新しい依頼を作業に取り込みます。

今回も数分かかるため、休憩を取り、ここまでに学んだ内容を振り返る時間にできます。

## まとめと次の手順

このレッスンでは、GitHub Copilot クラウドエージェントの監視と誘導を行う中心的な場所である Copilot エージェントページを確認しました。このミッションコントロールでは、実行中および完了したタスクを追跡し、進行中の作業を確認して、タスクの範囲や指示を変更できます。

次の概念を確認しました。

- ミッションコントロールとエージェントページでクラウドエージェントのタスクを監視しました。
- 進行中のセッションに追加機能を依頼し、作業の方向を調整しました。

Copilot がアクセシビリティ機能を実装している間に、Copilot が作成した[プルリクエストを反復して改善します][next-lesson]。
